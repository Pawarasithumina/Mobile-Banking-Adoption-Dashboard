# Mobile Banking Adoption Dashboard – Sri Lanka

##  Project Overview

**Mobile Banking Adoption Dashboard – Sri Lanka** is an interactive data analytics dashboard developed using **Microsoft Excel** to analyze mobile banking adoption and usage patterns among people in Sri Lanka.

The project explores how different demographic and behavioral factors may be associated with mobile banking adoption. The analysis focuses on variables such as **age, gender, income level, district, trust, privacy concerns, awareness, and application usability**.

The dashboard transforms the underlying survey/data records into interactive visualizations using **Pivot Tables, Pivot Charts, Slicers, and data-cleaning techniques**. This allows users to filter the data and examine differences between mobile banking users and non-users.

The project demonstrates practical skills in **data cleaning, exploratory data analysis, Excel-based dashboard development, and communicating insights through interactive visualizations**.

---

##  Project Objectives

The main objectives of this project were to:

* Analyze mobile banking adoption patterns in Sri Lanka.
* Examine adoption across different demographic groups.
* Compare mobile banking users and non-users.
* Explore the relationship between trust and mobile banking adoption.
* Analyze the impact of privacy concerns on usage.
* Examine the role of awareness in mobile banking adoption.
* Investigate how application usability relates to user adoption.
* Identify differences across income groups and districts.
* Present the findings through an interactive Excel dashboard.

##  Dashboard Overview

The dashboard provides multiple views of mobile banking adoption and the factors associated with it.

### 1. Adoption by Age Group

This analysis compares mobile banking adoption across different age categories.

It helps identify differences in adoption patterns between younger and older demographic groups.

### 2. Adoption by Gender

The dashboard compares mobile banking adoption between different gender groups.

This provides a demographic perspective on how mobile banking usage is distributed within the dataset.

### 3. Adoption by Income Level

Income categories are analyzed to examine differences in mobile banking adoption.

This allows users to explore whether adoption patterns vary across different income groups.

### 4. District-Level Analysis

The dashboard provides a geographical comparison of mobile banking adoption across districts in Sri Lanka.

This helps identify differences in adoption patterns between different locations represented in the dataset.

### 5. Trust Analysis

Trust is examined as one of the factors associated with mobile banking adoption.

The dashboard allows users to explore how different levels of trust are represented among users and non-users.

### 6. Privacy Concern Analysis

The project examines privacy concerns related to mobile banking.

This provides an understanding of how concerns about privacy are distributed within the dataset and how they differ between users and non-users.

### 7. Awareness Analysis

The dashboard examines the level of awareness about mobile banking services.

This helps explore the relationship between awareness and adoption within the collected data.

### 8. Application Usability

The analysis considers the perceived usability of mobile banking applications.

This allows users to explore how usability-related responses are distributed among mobile banking users and non-users.

##  Dashboard Features

### Interactive Slicers

Excel slicers allow users to filter the dashboard based on relevant categories.

Users can interactively explore the data without manually filtering individual tables.

### Pivot Tables

Pivot Tables are used to summarize the underlying dataset and calculate important counts and comparisons.

### Pivot Charts

Pivot Charts transform the summarized data into visual representations that make patterns easier to identify.

### User vs. Non-User Comparison

A key component of the dashboard is the comparison between people who use mobile banking services and those who do not.

This helps identify differences in demographic and behavioral characteristics between the two groups.

### Interactive Data Exploration

By combining Pivot Tables, Pivot Charts, and Slicers, the dashboard allows users to explore multiple dimensions of the dataset from a single interface.

##  Data Preparation

* Organizing demographic variables.

* Ensuring the dataset was suitable for Pivot Table analysis.

The cleaned dataset was then used as the foundation for the Excel dashboard.
